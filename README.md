## Packages & Modules

The "packages-modules" directory contains the example application for learning how Go packages and modules work.

### Compile

From the root of the repository, run:

`go build -o packages-modules-app ./packages-modules`

This compiles the "packages-modules" package and creates an executable named "packages-modules-app" in the root directory.

### Run

After compiling, run the executable:

`./packages-modules-app`

Source structure

```
packages-modules/
├── event/
│   └── event.go
└── main.go
```
